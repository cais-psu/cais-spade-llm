# Testbed and Case Studies

The proposed work will be validated on a dual-arm robotic assembly cell built around the NIST Assembly Task Board (ATB), a standardised manufacturing benchmark that captures the essential difficulties of real factory operations — heterogeneous parts, tight insertion tolerances, multi-step dependencies, and shared workspace coordination — in a footprint that fits on a benchtop. The cell pairs two heterogeneous collaborative arms: a Universal Robots UR5e with an OnRobot RG2 parallel-jaw gripper and a UFactory xArm6 with its stock parallel gripper. The UR5e is driven through the official ur_robot_driver ROS 2 Humble stack with MoveIt2 motion planning, while the xArm6 is commanded through the UFactory xArm Python SDK; both arms expose the same high-level skill set (pick-approach, pick-grasp, place-approach, place-insert, move-home) to the agentic layer, so the network can reason over them as interchangeable resources. Two Prusa MK3 and MK4 3D printers sit on either side of the workcell as upstream resources: the ATB parts themselves — small, medium, and large gears plus small, medium, and large circular and rectangular pins — are 3D-printed in-house from versioned OpenSCAD sources, and each printer is reachable by exactly one arm, so coordinated assemblies require the two robots to collaborate across heterogeneous resource islands rather than execute in isolation. This makes the cell a deliberately small but faithful microcosm of factory-scale operations: multiple production resources, cross-resource dependencies, dynamic disruptions, and the need for distributed reasoning under shared safety constraints. The same cell is mirrored by a Gazebo Classic 11 digital twin that loads from the identical JSON resource manifests used to drive the physical hardware — every robot, gripper, workspace bound, named pose, and failure scenario has both a simulation and a real branch — so the meshed agentic network sees a consistent interface across simulation and execution and can use the digital twin to parameterise rollouts, collect outcomes, and feed the results back into runtime decisions without changing the control stack.

We anticipate exercising the testbed through a small set of case studies that progressively stress different parts of the proposed meshed agentic architecture. The first case study takes a high-level natural-language instruction from a human operator (for example, "build the four-part gear-and-pin assembly") and asks the agentic network to decompose the request into per-resource subgoals, schedule pick-and-place operations across both arms and both 3D printers, and execute end-to-end on the ATB. This exercises the full natural-language to distributed-control pipeline on a representative four-part assembly that already exists in the testbed, in which each arm must pick a printed part from its reachable Prusa printer and insert it into the shared board. The second case study brings the digital twin explicitly into the loop: before committing to physical execution, the agentic network parameterises the Gazebo twin with several candidate schedules for the same assembly (different arm assignments, different staging orders, different printer-to-arm pairings), runs the simulated rollouts, parses makespan and collision data, and selects the best schedule to deploy on the real cell — directly instantiating the proposal objective of agentic systems that parameterise simulators, run them, collect output data, and provide optimised commands at runtime on a concrete dual-resource scheduling problem.

The third case study focuses on resilience under disruption. Using the failure scenarios already declared in the resource manifests (large-gear slippage on either arm, gripper miss, perception drop-out, and similar events), we will run controlled fault-injection campaigns to measure how the meshed agentic architecture handles failures without operator intervention, comparing a baseline that hands every disruption back to the human against the proposed system's LLM-assisted recovery loop and reporting autonomous recovery rate, human interventions per completed task, and the makespan overhead introduced by automated recovery. The fourth case study probes how cleanly the architecture absorbs new factory nodes by adding a third upstream resource — a second assembly fixture or an additional 3D printer — through a new JSON manifest only, with no agent-side code changes; we will measure how quickly the network re-plans to exploit the new resource and whether throughput scales as expected, providing an early empirical signal on extrapolating the meshed agentic network from a benchtop cell to the larger factory-scale deployments envisaged with PNNL and Siemens.
